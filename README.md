# Cистема автоматической конфигурации AutoML-пайплайнов на основе запросов на естественном языке

Система позволяет пользователю описать ML-задачу на естественном языке и автоматически сформировать конфигурацию ML-пайплайна, соответствующую задаче и предпочтениям пользователя

## План разработки

> [!NOTE]
> Разработка проекта будет проходить поэтапно в соответствии с чекпойнтами годового проекта. На каждом этапе система будет постепенно развиваться от базового ML-ядра до полноценного сервиса автоматической конфигурации ML-пайплайнов.

### 1. Исследование задачи и проектирование системы

- Выбрать датасеты для разработки и тестирования
- Подготовить тестовые сценарии с запросами пользователей и правильными конфигурациями
- Определить, какую информацию система должна получать из запроса пользователя
- Выделить основные элементы конфигурации: таргет, метрику, валидацию, ограничения и требования к результату
- Спроектировать общую схему работы системы
- Определить набор инструментов системы и структуру базы знаний по типовым ML-задачам

### 2. Разработка базовой версии системы

- Реализовать анализ структуры загруженного датасета
- Определять кандидатов в таргет, баланс классов, даты, идентификаторы, группы и пропуски
- Добавить поиск потенциально проблемных признаков и утечек
- Создать базовую версию системы с фиксированным набором уточняющих вопросов
- Реализовать формирование базовой конфигурации ML-задачи
- Подключить готовую AutoML-систему через общую обёртку и проверить подход на тестовых сценариях

### 3. Создание ML-сервиса

- Разработать сервис для загрузки датасета и общения с пользователем
- Добавить отображение и ручное редактирование полученной конфигурации
- Реализовать построение таргета и подготовку данных перед запуском AutoML
- Добавить проверку утечек и выбор подходящего разбиения данных
- Реализовать полный сценарий от постановки задачи до получения результатов
- Добавить отчёт с результатами в терминах исходной бизнес-задачи, анализом ошибок и предупреждениями

### 4. Разработка адаптивной конфигурации на естественном языке

- Научить систему определять, какой информации не хватает для постановки задачи
- Реализовать выбор между уточняющим вопросом и использованием разумного значения по умолчанию
- Учитывать при диалоге свойства датасета и ограничения пользователя
- Добавить обработку противоречивых требований
- Использовать базу знаний и объяснять пользователю принятые решения
- Сравнить разработанный подход с базовой версией системы

### 5. Исследование и интеграция нейросетевых моделей

- Сравнить разные языковые модели в роли агента
- Проанализировать ошибки агента и улучшить обработку запросов
- Исследовать нейросетевые модели для табличных данных в AutoML-инструментах
- Добавить возможность использовать выбранные модели через общую обёртку
- Научить агента учитывать свойства задачи и данных при выборе подходящих моделей

### 6. Интеграция MLflow и итоговая оценка системы

- Подключить MLflow для сохранения параметров, метрик, моделей и конфигураций
- Обеспечить воспроизводимость экспериментов
- Добавить возможность сравнения разных версий системы и запусков
- Оценить качество постановки задачи и сформированной конфигурации
- Оценить качество уточняющих вопросов и итоговых результатов обучения
- Сравнить систему с AutoML с настройками по умолчанию и с прямым использованием языковой модели
