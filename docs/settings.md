# Настройки

Настройки, определяющие особенности поведения сервиса. Изменяются пользователем через UI.

> [!NOTE]
> Настройки не передаются в AutoGluon как параметры, но могут использовать его API.

#### `save_model_artifact`

- **Тип:** Boolean
- **Допустимые значения:** `true`, `false`
- **Обязательный:** Нет
- **По умолчанию:** `false`

Если `true`, сервис должен сериализовать и сохранить на диск наиболее производительную ансамблевую модель для последующего инференса через API.

#### `return_feature_importance`

- **Тип:** Boolean
- **Допустимые значения:** `true`, `false`
- **Обязательный:** Нет
- **По умолчанию:** `true`

Если `true`, сервис должен извлечь таблицу с итоговым влиянием признаков на результат.

#### `return_leaderboard`

- **Тип:** Boolean
- **Допустимые значения:** `true`, `false`
- **Обязательный:** Нет
- **По умолчанию:** `true`

Если `true`, сервис должен извлечь полный лидерборд всех обученных моделей.

#### `extra_info`

- **Тип:** Boolean
- **Допустимые значения:** `true`, `false`
- **Обязательный:** Нет
- **По умолчанию:** `false`

Если `true`, сервис должен выводить детальную информацию о каждой модели на финальном лидерборде. Используется если включена настройка `return_leaderboard`.

#### `refit_full`

- **Тип:** Boolean или String
- **Допустимые значения:** `true`, `false`
- **Обязательный:** Нет
- **По умолчанию:** `false`

Если `true`, сервис должен повторно обучить финальные лучшие архитектуры на объединённых обучающей и валидационной выборках для повышения предсказательной силы и уменьшения размера моделей.
