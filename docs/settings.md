# Настройки

Настройки, определяющие дополнительные действия сервиса при обработке\
и представлении результатов обучения. Могут задаваться системой или\
изменяться пользователем через UI.

> [!NOTE]
> Настройки относятся к поведению сервиса и не входят в конфигурацию ML-задачи, формируемую агентом.\
> Для их реализации могут использоваться методы и параметры API AutoGluon.

#### `save_model_artifact`

- **Тип:** Boolean
- **Допустимые значения:** `true`, `false`
- **Обязательный:** Нет
- **По умолчанию:** `false`

Если `true`, сервис должен сохранить отдельный артефакт лучшей модели, выбранной AutoGluon\
по основной метрике на валидационных данных, для последующего инференса через API.

Лучшая модель может быть как отдельным алгоритмом, так и ансамблем. При экспорте должны\
сохраняться все необходимые зависимости модели. AutoGluon автоматически сохраняет\
результаты обучения, поэтому настройка управляет созданием отдельного артефакта\
для использования вне процесса обучения.

#### `return_feature_importance`

- **Тип:** Boolean
- **Допустимые значения:** `true`, `false`
- **Обязательный:** Нет
- **По умолчанию:** `true`

Если `true`, сервис должен рассчитать и предоставить таблицу важности признаков для\
выбранной модели с использованием **predictor.feature_importance()**.

Важность оценивается по изменению качества предсказаний при перемешивании значений\
признака и не означает его причинного влияния на результат. Расчёт требует\
дополнительных вычислений и подходящих данных для оценки.

#### `return_leaderboard`

- **Тип:** Boolean
- **Допустимые значения:** `true`, `false`
- **Обязательный:** Нет
- **По умолчанию:** `true`

Если `true`, сервис должен предоставить таблицу сравнения доступных обученных моделей\
с их метриками и характеристиками с использованием **predictor.leaderboard()**.

Полнота таблицы зависит от выбранной конфигурации обучения и сохранённых моделей.

#### `extra_info`

- **Тип:** Boolean
- **Допустимые значения:** `true`, `false`
- **Обязательный:** Нет
- **По умолчанию:** `false`

Если `true`, сервис должен включить дополнительные характеристики моделей в таблицу\
результатов с использованием параметра **extra_info=True** метода **predictor.leaderboard()**.

Применяется только при включённой настройке **return_leaderboard**.

#### `refit_full`

- **Тип:** Boolean или String
- **Допустимые значения:** `true`, `false`
- **Обязательный:** Нет
- **По умолчанию:** `false`

Управляет повторным обучением моделей на объединённых обучающей и внутренней валидационной выборках.
- `false` — повторное обучение отключено;
- `true` или `"all"` — повторно обучаются все модели;
- `"best"` — повторно обучается лучшая модель и, при необходимости, модели, от которых она зависит.

Повторное обучение может улучшить качество отдельных моделей или ускорить инференс, но не\
гарантирует повышения точности. Оно требует дополнительных вычислений и не должно\
использовать независимую тестовую выборку.

Для реализации используется параметр **refit_full** метода **fit()** либо отдельный вызов **predictor.refit_full()**.
