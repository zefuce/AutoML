# Конфигурация

Список параметров, предназначенный для генерации финального `structured_output` AI агентом для передачи в AutoGluon.

> [!NOTE]
> Передача в запрос к LLM осуществляется через модели Pydantic.

### 1. Таргет

Определяет цель предсказания.

#### `label`

- **Тип:** String
- **Допустимые значения:** валидные имена столбцов
- **Обязательный:** Да
- **По умолчанию:** -

Столбец с истинными значениями, который модели будут учиться предсказывать.

#### `problem_type`

- **Тип:** String Enum
- **Допустимые значения:** `None`, `binary`, `multiclass`, `regression`, `quantile`
- **Обязательный:** Нет
- **По умолчанию:** `None`

Принудительно задаёт конкретную постановку задачи машинного обучения. Если указан `None`, тип определяется на основе распределения целевых классов.

## 2. Метрики

Определяет, как модели математически оцениваются, оптимизируются и ранжируются в процессе выполнения.

#### `eval_metric`

- **Тип:** String Enum
- **Допустимые значения:** `accuracy`, `f1`, `roc_auc`, `precision`, `recall`, `log_loss`, `rmse`, `mae`, `r2`
- **Обязательный:** Да
- **По умолчанию:** -

Основная метрика, используемая для управления оптимизацией модели, подбором гиперпараметров и ранней остановкой.

#### `extra_metrics`

- **Тип:** Array of Strings
- **Допустимые значения:** Любые из не выбранных значений `eval_metric`.
- **Обязательный:** Нет
- **По умолчанию:** `[]`

Дополнительные метрики оценки, вычисляемые на финальном лидерборде. Не влияют на процесс оптимизации. Используется если включена [настройка](settings.md) `return_leaderboard`.

## 3. Инженерия признаков

Определяет параметры, изменяющие столбцы признаков перед передачей входных данных в пайплайны обучения.

#### `ignored_columns`

- **Тип:** Array of Strings
- **Допустимые значения:** валидные имена столбцов
- **Обязательный:** Нет
- **По умолчанию:** `None`

Явно перечисляет столбцы, которые должны быть полностью удалены перед обучением.

#### `type_map_raw`

- **Тип:** Dict или String
- **Допустимые значения:** `infer` или словарь: тип - имя столбца
- **Обязательный:** Нет
- **По умолчанию:** `infer`

Используется для ручного переопределения типов столбцов.

## 4. Валидация

Определяет стратегии, используемые для оценки качества моделей на новых данных с целью защиты от переобучения.

#### `validation_procedure`

- **Тип:** String Enum
- **Допустимые значения:** `auto`, `holdout`, `cross_validation`
- **Обязательный:** Нет
- **По умолчанию:** `auto`

Стратегия разбиения данных на обучающую и валидационную выборки. `auto` позволяет оптимизировать процесс, если хватает времени выполнения.

#### `holdout_frac`

- **Тип:** Float
- **Допустимые значения:** `0.0`-`0.5`
- **Обязательный:** Нет
- **По умолчанию:** `None`

Доля датасета, выделяемая под валидацию (применимо только если `strategy` установлено в `holdout`).

#### `auto_stack`

- **Тип:** Boolean
- **Допустимые значения:** `true`, `false`
- **Обязательный:** Нет
- **По умолчанию:** `false`

Автоматизирует многослойное построение ансамблей и циклы bagging, если выделенного бюджета времени достаточно.

#### `num_bag_folds`

- **Тип:** Integer
- **Допустимые значения:** `2`-`10`
- **Обязательный:** Нет
- **По умолчанию:** `None`

Точное количество фолдов, используемое для повторной кросс-валидации или bagging-ансамблей.

#### `num_stack_levels`

- **Тип:** Integer
- **Допустимые значения:** `0`-`3`
- **Обязательный:** Нет
- **По умолчанию:** `None`

Управляет количеством слоёв стекинга, последовательно построенных поверх предсказаний базовых алгоритмов.

## 5. Ограничения и требования к результату

Определяет физические ограничения, лимиты использования оборудования и общие правила процесса обучения.

#### `time_limit`

- **Тип:** Integer
- **Допустимые значения:** `>= 10` (секунды)
- **Обязательный:** Да
- **По умолчанию:** -

Жёсткий потолок времени выполнения для всего процесса обучения. По достижении лимита работа завершается и возвращаются лучшие модели.

#### `presets`

- **Тип:** String Enum
- **Допустимые значения:** `best_quality`, `high_quality`, `good_quality`, `medium_quality`, `optimize_for_deployment`, `interpretable`
- **Обязательный:** Нет
- **По умолчанию:** `medium_quality`

Предустановленные профили качества, балансирующие предсказательные возможности модели между длительностью обучения и потреблением ресурсов.

#### `excluded_model_types`

- **Тип:** Array of Strings
- **Допустимые значения:** `GBM`, `NN_TORCH`, `CAT`, `XGB`, `FASTAI`, `RF`, `XT`
- **Обязательный:** Нет
- **По умолчанию:** `[]`

Список алгоритмов, которые следует исключить из выбора.

#### `num_cpus`

- **Тип:** Integer или String
- **Допустимые значения:** `auto` или положительное целое число
- **Обязательный:** Нет
- **По умолчанию:** `auto`

Ограничивает количество вычислительных ядер, выделяемых для обучения.

#### `num_gpus`

- **Тип:** Integer или String
- **Допустимые значения:** `auto` или положительное целое число
- **Обязательный:** Нет
- **По умолчанию:** `auto`

Устанавливает ограничения на использование графических вычислений. Передача `0` принудительно переводит все модели на CPU.

## 6. Окружение

Определяет условия окружения и телеметрии.

#### `path`

- **Тип:** String
- **Допустимые значения:** -
- **Обязательный:** Нет
- **По умолчанию:** `None`

Корневая папка для хранения, в которую сериализуются и сохраняются модели, чекпоинты и веса.

#### `verbosity`

- **Тип:** Integer
- **Допустимые значения:** `0`, `1`, `2`, `3`, `4`
- **Обязательный:** Нет
- **По умолчанию:** `2`

Управляет глубиной логирования.
