# Тестирование системы

Документация базы знаний тестовых сценариев и механики автоматического тестирования агента.

> [!NOTE]
> Тесты не выдают вердикт «прошёл / не прошёл»: каждая проверка считается как метрика.

## Ключевые принципы

- **Чёрный ящик.** Тестовый harness общается с системой через тот же HTTP API, что и пользовательский интерфейс.
- **Метрики, а не вердикты.** Каждая проверка даёт число или долю.
- **Стоимость и качество равноправны.** Число вопросов к пользователю, стоимость и время LLM-вызовов измеряются наравне с качеством конфигурации.
- **Пустой эталон — валидный эталон.** AutoGluon сам хорошо обрабатывает многие проблемы данных; сценарии, где эталонная подготовка данных — «ничего не делать», обязательны, иначе тесты будут вознаграждать избыточную обработку.
