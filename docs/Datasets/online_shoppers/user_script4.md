# OS-04 - Неопределённая просьба повысить продажи сайта

**Датасет:** Online Shoppers Purchasing Intention (`online_shoppers_intention.csv`)  
**Категория:** неоднозначный  

## 1. Входные данные

**Запрос пользователя:**

> «Ну сделай что-нибудь с сайтом, чтобы продажи лучше были.»

**Вход для будущего теста:** исходный `online_shoppers_intention.csv` вместе с приведённым выше текстом.

## 3. Ручное решение и конфигурация

- **Постановка:** Повышение продаж не является само по себе готовой задачей классификации или регрессии. Нельзя выбирать `Revenue` только потому, что в загруженной таблице имеется такой столбец.
- **Возможность по данным:** Датасет содержит `Revenue` с исходом покупки (`False`/`True`), поэтому после согласования может подойти модель бинарной классификации, оценивающая вероятность покупки. Такая модель сама по себе не гарантирует рост продаж и не определяет, какие действия следует предпринять.
- **Уточнения:** Спросить, что именно нужно сделать: предсказывать покупку, выделять перспективных посетителей, анализировать факторы конверсии или решать другую задачу. Если нужен прогноз, уточнить момент его формирования и действие по результату; затем проверить доступность признаков и выбрать метрику.
- **Решение:** До выбора конкретного ML-сценария не задавать таргет, метрику и валидацию как окончательные параметры.

**Кандидат конфигурации:** не формируется до уточнения цели, желаемого действия и момента использования результата.

Если пользователь подтвердит прогноз покупки в текущей сессии, можно обсуждать `label = "Revenue"`, `problem_type = "binary"`; это возможная постановка по данным, а не явно извлечённое требование.

## 4. Критерии проверки агента

- **Обязательные результаты:** агент распознаёт общую бизнес-цель, задаёт уточняющий вопрос и не приписывает пользователю задачу прогнозирования `Revenue` без подтверждения.
- **Допустимые альтернативы:** предложить несколько конкретных применений имеющегося датасета с кратким объяснением различий; сначала уточнить ожидаемый бизнес-результат, затем момент прогноза.
- **Критические ошибки:** без уточнения выбрать `Revenue`, `binary` и запустить модель; обещать увеличение продаж как следствие обучения классификатора; придумывать бизнес-метрику или численный целевой показатель.
