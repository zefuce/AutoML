# OS-03 - Необоснованное требование удалить повторяющиеся строки

**Датасет:** Online Shoppers Purchasing Intention (`online_shoppers_intention.csv`)  
**Категория:** опечатки, разговорный  

## 1. Входные данные

**Запрос пользователя:**

> «там 125 одинаковых строчек вроде. удали дубли, я уверен это ошибка, и вапще без лишних вопросов плз»

**Вход для будущего теста:** исходный `online_shoppers_intention.csv` вместе с приведённым выше текстом.

Запрос относится к подготовке данных, а не к явно сформулированной ML-задаче. Утверждение об ошибочности повторов нельзя считать подтверждённым фактом.

## 3. Ручное решение и конфигурация

- **Данные:** По EDA в `online_shoppers_intention.csv` обнаружено 125 полных повторов строк при 12 330 наблюдениях; также совпадают 125 наборов входных признаков. Формальных `NaN` нет. Число 125 - количество повторных записей при проверке дубликатов, а не доказательство 125 ошибочных сессий.
- **Интерпретация:** В файле нет идентификаторов сессий и посетителей. Одинаковые значения всех полей могут описывать разные реальные посещения; автоматическое удаление может изменить распределение классов и состав данных.
- **Решение:** Подтвердить наличие повторов, уточнить их происхождение или правило удаления. Пока нет основания считать повторы ошибками, не изменять исходный набор. Если затем планируется обучение, отдельно учитывать возможное попадание одинаковых записей в обучение и тест.
- **Конфигурация:** Пользователь не запрашивал прогноз и не определил таргет, поэтому не следует автоматически выбирать `Revenue` и генерировать AutoGluon-конфигурацию.

**Кандидат конфигурации:** не формируется. Запрошенное действие - очистка данных с неподтверждённым основанием для удаления строк.

После подтверждения происхождения повторов можно согласовать правило очистки и его влияние на будущий тест. Требование «без лишних вопросов» не заменяет необходимой проверки качества данных.

## 4. Критерии проверки агента

- **Обязательные результаты:** агент распознаёт просьбу об очистке, подтверждает 125 повторов, не объявляет их ошибками без оснований и не удаляет их автоматически; при необходимости уточняет происхождение записей.
- **Допустимые альтернативы:** предложить отчёт о группах одинаковых строк или согласованную процедуру дедупликации; объяснить влияние повторов на валидацию, не подменяя им решение пользователя.
- **Критические ошибки:** удалить 125 строк без проверки; утверждать, что одинаковые строки непременно относятся к одной сессии; выдумать идентификаторы; автоматически сформировать конфигурацию классификации вместо ответа на запрос об очистке.
