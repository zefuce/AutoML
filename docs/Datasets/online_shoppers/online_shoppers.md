# Online Shoppers Purchasing Intention - результат исследования

**Задача.** Предсказать, завершится ли посещение интернет-магазина покупкой (`Revenue`), по признакам текущей сессии. Момент формирования прогноза и доступность накопленных показателей требуют уточнения.

**Данные.** UCI Online Shoppers Purchasing Intention, `online_shoppers_intention.csv`: 12 330 сессий, 17 входных признаков, один таргет `Revenue`. Источник и описание: [UCI Machine Learning Repository](https://archive.ics.uci.edu/dataset/468/online+shoppers+purchasing+intention+dataset). Расчёты и графики приведены в `online_shoppers.ipynb`.

## 1. Первичный анализ

`Revenue` принимает значения `False` и `True`. Исходная постановка - бинарная классификация. Среди входных признаков 10 числовых показателей и 7 категориальных полей. Часть категорий представлена целочисленными кодами.

### Смысл признаков

| Признак | Что содержит | На что обратить внимание |
|---|---|---|
| `Administrative` | Количество просмотренных административных страниц | Много нулей, длинный хвост |
| `Administrative_Duration` | Суммарное время на административных страницах | Нулевые длительности, выбросы |
| `Informational` | Количество информационных страниц | Большинство значений нулевые |
| `Informational_Duration` | Время на информационных страницах | Большинство значений нулевые |
| `ProductRelated` | Количество просмотренных товарных страниц | Выбросы, изменение в ходе сессии |
| `ProductRelated_Duration` | Время на товарных страницах | Выбросы, связь с количеством страниц |
| `BounceRates` | Показатель отказов для посещённых страниц | Связь с `ExitRates` |
| `ExitRates` | Показатель выходов для посещённых страниц | Связь с таргетом |
| `PageValues` | Средняя ценность посещённых страниц по данным веб-аналитики | Нули, доступность при прогнозе, риск утечки |
| `SpecialDay` | Близость даты к специальному дню | Много нулей |
| `Month` | Месяц посещения | Неравные размеры групп, нет точной даты |
| `OperatingSystems` | Код операционной системы | Категория, а не числовая шкала |
| `Browser` | Код браузера | Категория, редкие значения |
| `Region` | Код региона | Категория, не числовая шкала |
| `TrafficType` | Код источника трафика | Категория, редкие значения |
| `VisitorType` | Тип посетителя | Неравные размеры групп |
| `Weekend` | Признак выходного дня | Два значения |
| `Revenue` | Завершилась ли сессия покупкой | Целевая переменная |

## 2. Основные статистики и таргет

| Показатель | Результат |
|---|---:|
| Всего сессий | 12 330 |
| `Revenue = False` | 10 422 (84,53%) |
| `Revenue = True` | 1 908 (15,47%) |
| Числовых входных признаков | 10 |
| Категориальных входных признаков | 7 |

Положительный класс составляет 15,47%. Постоянный прогноз `False` дал бы accuracy 84,53%, не обнаружив ни одной покупки.

## 4. Диапазоны, нули и распределения

У исследованных числовых показателей отрицательных значений нет. `BounceRates` и `ExitRates` находятся в диапазоне 0–0,2, `SpecialDay` - в диапазоне 0–1.

| Признак | Доля нулей |
|---|---:|
| `Administrative` | 46,78% |
| `Informational` | 78,66% |
| `ProductRelated` | 0,31% |
| `PageValues` | 77,86% |
| `SpecialDay` | 89,85% |

При нулевом количестве страниц положительная длительность не встречается. Строки с положительным количеством страниц и нулевой длительностью: `Administrative` - 135, `Informational` - 226, `ProductRelated` - 717.

Метод IQR применён к трём количественным признакам:

| Признак | Медиана | IQR-сигналы | Доля строк |
|---|---:|---:|---:|
| `ProductRelated` | 18 | 987 | 8,00% |
| `ProductRelated_Duration` | 598,94 | 961 | 7,79% |
| `Administrative_Duration` | 7,5 | 1 172 | 9,51% |

Для `PageValues` первый и третий квартили равны нулю. Общий IQR для него не использовался. Выявленные большие значения не считаются ошибками без дополнительных оснований.

## 7. Проверка `PageValues` и момента прогноза

| Группа | Сессий | Доля покупок |
|---|---:|---:|
| `PageValues = 0` | 9 600 | 3,85% |
| `PageValues > 0` | 2 730 | 56,34% |

`PageValues` сильно связан с исходом сессии. По описанию UCI этот показатель рассчитывается на основе веб-аналитики посещённых страниц и транзакций. Для использования в прогнозе необходимо уточнить, формируется ли он только из заранее доступной статистики или содержит сведения о текущем результате.

Количество и суммарная длительность посещений зависят от этапа сессии. Полной даты, времени отдельного события и идентификатора посетителя в таблице нет. Строгое хронологическое разбиение по имеющимся полям не восстанавливается.

## 8. Итоги и эталон ожидаемых действий агента

| Что нужно решить | Обоснованный ориентир |
|---|---|
| Что предсказывать | `Revenue`, завершение сессии покупкой |
| Тип задачи | Бинарная классификация |
| Дисбаланс | Учитывать 15,47% положительных сессий |
| Пропуски | Формальных `NaN` нет |
| Дубликаты | 125 полных повторов; не удалять без выяснения происхождения |
| Категории | `OperatingSystems`, `Browser`, `Region`, `TrafficType` - категориальные коды |
| Выбросы | Не удалять длинные посещения по одному правилу IQR |
| Момент прогноза | Уточнять, когда формируется прогноз и какие показатели доступны |
| Риск утечки | Проверять расчёт и доступность `PageValues` |
| Метрика | Учитывать precision, recall, PR-AUC и стоимость решений по прогнозу |
| Валидация | Учитывать отсутствие точных дат и идентификаторов; случайное разбиение не имитирует будущие периоды |
