# AH-01 - Прогноз стоимости дома перед сделкой

**Датасет:** Ames Housing (`train.csv`)  
**Категория:** короткий  

## 1. Входные данные

**Запрос пользователя:**

> «Сколько будет стоить дом перед сделкой?»

**Вход для будущего теста:** исходный `train.csv` вместе с приведённым выше текстом.

## 3. Ручное решение и конфигурация

- **Задача:** `label = "SalePrice"`, `problem_type = "regression"`. По EDA в `train.csv` 1 460 домов, а `SalePrice` - числовая цена продажи в долларах США.
- **Данные и признаки:** Исключить идентификатор `Id`. Различать неизвестные значения и отсутствие гаража, подвала или бассейна: часть `NA` имеет смысл «объекта нет», а `None` может быть отдельной категорией. Проверить тип числовых кодов, например `MSSubClass`. До сделки доступность `SaleType`, `SaleCondition`, `MoSold`, `YrSold` не подтверждена, поэтому в кандидате они исключены.
- **Метрика:** `mean_absolute_error` - обоснованный начальный выбор для оценки ошибки в долларах, не указанный пользователем. Допустима `root_mean_squared_error` при объяснении большего штрафа за крупные промахи.
- **Валидация:** Для предварительной оценки допустимо независимое случайное разбиение до обучения; внутренняя валидация AutoGluon - `auto`. Случайный тест не является проверкой прогноза для более поздних сделок.

**Кандидат конфигурации** (после указанных проверок):

```json
{
  "label": "SalePrice",
  "problem_type": "regression",
  "eval_metric": "mean_absolute_error",
  "ignored_columns": [
    "Id",
    "SaleType",
    "SaleCondition",
    "MoSold",
    "YrSold"
  ],
  "validation_procedure": "auto",
  "presets": "medium_quality"
}
```

`time_limit` в запросе отсутствует - сервис применяет свой лимит по умолчанию. Список исключений консервативен и может измениться после проверки реального момента доступности полей; `ignored_columns` и `validation_procedure` реализуются обёрткой.

## 4. Критерии проверки агента

- **Обязательные результаты:** агент определяет `SalePrice` и регрессию, не использует `Id`, корректно рассматривает структурные пропуски, выбирает подходящую метрику и проверяет доступность сведений до сделки.
- **Допустимые альтернативы:** `root_mean_squared_error` вместо `mean_absolute_error`; использование отдельных полей о продаже, если достоверно подтверждено, что они известны на момент прогноза. Формулировки и порядок действий не обязаны совпадать с эталоном.
- **Критические ошибки:** выбрать классификацию вместо регрессии; включить `Id` как предиктор без обоснования; автоматически удалить все строки с `NA`; использовать сведения, появляющиеся только после сделки, или приписать пользователю неуказанную метрику.
