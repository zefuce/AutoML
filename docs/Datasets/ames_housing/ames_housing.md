# Ames Housing - результат исследования

**Задача.** Предсказать цену продажи дома в городе Эймс (`SalePrice`) по характеристикам недвижимости. Момент формирования прогноза и доступность сведений об условиях продажи требуют уточнения.

**Данные.** Kaggle House Prices - Advanced Regression Techniques, исходный `train.csv`: 1 460 строк, 81 столбец, из них 79 входных признаков, идентификатор `Id` и таргет `SalePrice`. Описание признаков - `data_description.txt`. Источник: [Kaggle](https://www.kaggle.com/competitions/house-prices-advanced-regression-techniques/data). Расчёты и графики приведены в `ames_housing.ipynb`.

## 1. Первичный анализ

`SalePrice` - числовая цена продажи в долларах США. Исходная постановка - регрессия. Среди входных признаков 36 числовых и 43 категориальных по типу данных. `MSSubClass` и отдельные календарные поля закодированы числами, но не являются непрерывными измерениями.

### Смысл признаков

| Признак или группа | Что содержит | На что обратить внимание |
|---|---|---|
| `Id` | Идентификатор записи | Не является характеристикой дома |
| `SalePrice` | Цена продажи, доллары | Таргет, асимметрия и большие значения |
| `MSSubClass`, `MSZoning` | Тип и зонирование объекта | Коды категорий |
| `Neighborhood` | Район | Размеры групп, различия цен |
| `LotArea`, `LotFrontage` | Площадь участка, длина фасада | Выбросы, пропуски |
| `GrLivArea`, `1stFlrSF`, `TotalBsmtSF` | Жилая площадь и площади этажей | Большие значения, нулевой подвал |
| `OverallQual`, `OverallCond` | Оценки качества и состояния | Порядковые значения, связь с ценой |
| `YearBuilt`, `YearRemodAdd`, `GarageYrBlt` | Годы постройки и обновлений | Согласованность с годом продажи |
| `GarageType`, `GarageArea`, `GarageCars` | Характеристики гаража | Структурные пропуски |
| `Fireplaces`, `FireplaceQu` | Камины и их качество | Структурные пропуски |
| `PoolArea`, `PoolQC` | Бассейн и качество | Очень редкие объекты |
| `Alley`, `Fence`, `MiscFeature` | Проезд, забор, дополнительные объекты | Большая доля отсутствующих объектов |

| `ExterQual`, `KitchenQual` | Качество отделки и кухни | Связь с ценой |
| `SaleType`, `SaleCondition` | Тип и условия продажи | Доступность на момент прогноза |
| `MoSold`, `YrSold` | Месяц и год продажи | Приблизительный временной порядок |
| Остальные признаки | Качество конструкций, оборудование, помещения | Разные типы и масштабы |

## 3. Пропуски и специальные значения

В исходном `train.csv` для отсутствующих и неприменимых значений используется `NA`. При чтении в ноутбуке оно распознаётся как `NaN`. По `data_description.txt` в отдельных признаках `NA` означает отсутствие объекта, например гаража или бассейна.

| Показатель | Результат |
|---|---:|
| Всего значений `NA`, прочитанных как `NaN`, среди входных признаков | 6 965 |
| Доля `NaN` среди входных ячеек | 6,04% |
| Признаков с `NaN` | 19 |
| Строк с `NaN` | 1 460 |
| Полностью заполненных строк | 0 |

| Признак | `NaN`, шт. | Доля строк |
|---|---:|---:|
| `PoolQC` | 1 453 | 99,52% |
| `MiscFeature` | 1 406 | 96,30% |
| `Alley` | 1 369 | 93,77% |
| `Fence` | 1 179 | 80,75% |
| `FireplaceQu` | 690 | 47,26% |
| `LotFrontage` | 259 | 17,74% |
| `GarageType` | 81 | 5,55% |
| `BsmtQual` | 37 | 2,53% |

Для `FireplaceQu`, `GarageType`, `PoolQC`, `BsmtQual` пропуски совпадают с отсутствием соответствующего объекта: 690, 81, 1 453 и 37 строк. В `MasVnrType` строковая категория `None` встречается 864 раза, отдельно от восьми `NaN`. Такое разделение важно для работы с признаками.

## 4. Дубликаты и проверка значений

Полных дубликатов, повторов `Id` и повторов наборов входных признаков без `Id` нет. Для `LotArea`, `GrLivArea`, `SalePrice` неположительных значений нет. `MoSold` находится в диапазоне 1-12.

В одной записи `YearRemodAdd` превышает `YrSold`. Для `YearBuilt` и `GarageYrBlt` таких случаев не найдено. Причина несогласованности неизвестна.

## 5. Числовые распределения и выбросы

Метод IQR применён к отдельным площадям и таргету для поиска необычных значений:

| Признак | Медиана | IQR-сигналы | Доля строк |
|---|---:|---:|---:|
| `SalePrice` | 163 000 | 61 | 4,18% |
| `LotArea` | 9 478,5 | 69 | 4,73% |
| `GrLivArea` | 1 464 | 31 | 2,12% |
| `TotalBsmtSF` | 991,5 | 61 | 4,18% |
| `GarageArea` | 480 | 21 | 1,44% |

Четыре дома имеют `GrLivArea > 4000`. Два из них при большой площади проданы за 184 750 и 160 000 долларов. Это нетипичные сочетания площади и цены. Нулевые `GarageArea` (81) и `TotalBsmtSF` (37) соответствуют отсутствию гаража и подвала.

## 6. Категориальные признаки и связь с ценой

Для всех строковых признаков рассчитаны частоты категорий и число уникальных значений. Для выбранных категорий дополнительно сравнены медианы цен.

| Признак | Наблюдение |
|---|---|
| `OverallQual` | Оценка 5: 397 домов, медиана 133 000 $; оценка 10: 18 домов, медиана 432 390 $ |
| `Neighborhood` | `OldTown`: 113 домов, медиана 119 000 $; `NridgHt`: 77 домов, медиана 315 000 $ |
| `ExterQual`, `KitchenQual` | Медианы цен различаются между категориями качества |
| `SaleCondition` | Размеры групп неравны; требуется учитывать момент получения сведений об условиях продажи |

Эти связи не учитывают остальные характеристики домов, поэтому не определяют самостоятельный вклад каждого признака в цену.

## 9. Итоги и эталон ожидаемых действий агента

| Что нужно решить | Обоснованный ориентир |
|---|---|
| Что предсказывать | `SalePrice`, стоимость дома в долларах |
| Тип задачи | Регрессия |
| Пропуски | Различать структурно отсутствующие объекты и неизвестные измерения; учитывать `None` отдельно от `NaN` |
| Идентификатор | Не использовать `Id` как самостоятельный предиктор |
| Категориальные коды | Проверять смысл `MSSubClass`, `MoSold`, `YrSold` |
| Ошибки и выбросы | Проверить несогласованный `YearRemodAdd` и большие площади, не удалять строки только по IQR |
| Риск утечки | Уточнить доступность `SaleType`, `SaleCondition` и календарных полей в момент прогноза |
| Метрика | MAE или RMSE в долларах; RMSE по логарифмам цен |
| Валидация | Сохранять порядок по годам и месяцам при оценке будущих продаж, точных дней нет |

## Как воспроизвести

Открыть `ames_housing.ipynb` в VS Code или Jupyter, установить `pandas`, `matplotlib`, `seaborn` и выполнить ячейки сверху вниз. Исходный `train.csv` должен лежать рядом с ноутбуком. Описание полей - `data_description.txt`.
