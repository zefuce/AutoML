# AH-03 - Требование удалить большие дома из выборки

**Датасет:** Ames Housing (`train.csv`)  
**Категория:** разговорный  

## 1. Входные данные

**Запрос пользователя:**

> «Уберите огромные дома из выборки. Они какие-то странные и портят всю картину, ну очевидно же.»

**Вход для будущего теста:** исходный `train.csv` вместе с приведённым выше текстом.

Запрос содержит требование к обработке данных, но не определяет ML-задачу. Слова «огромные» и «странные» не задают объективного правила удаления; внутри текста явного конфликта нет.

## 3. Ручное решение и конфигурация

- **Данные:** по EDA четыре дома имеют `GrLivArea > 4000` квадратных футов. Два из них проданы за 184 750 и 160 000 долларов - необычное сочетание площади и цены, но само по себе не доказательство ошибки.
- **Решение:** проверить эти записи, исходные значения и возможные причины отклонений. Уточнить, по какому признаку и порогу исключать объекты и для какой цели. Не удалять строки автоматически только на основании величины площади либо IQR.
- **Влияние на оценку:** удаление больших домов меняет целевую популяцию. Если правило очистки будет подтверждено, применять его воспроизводимо и не использовать `SalePrice` из независимой тестовой выборки для подгонки правил по результату.
- **Постановка задачи:** пользователь не просит явно прогнозировать цену и не задаёт метрику. Возможную регрессию по `SalePrice` можно обсуждать только как следующий шаг после уточнения цели.

**Кандидат конфигурации:** не формируется до уточнения запроса и устранения существенных неопределённостей.

До согласования критерия отбора и ML-задачи нужны объяснение риска и уточняющий вопрос, а не запуск обучения. Если речь только об очистке данных, конфигурация AutoGluon вообще не требуется.

## 4. Критерии проверки агента

- **Обязательные результаты:** агент распознаёт неопределённость правила удаления, обращается к распределению `GrLivArea` и необычным объектам, просит уточнить критерий и не удаляет большие дома без обоснования.
- **Допустимые альтернативы:** предложить просмотр четырёх записей с `GrLivArea > 4000` либо другой диагностический критерий без автоматического удаления; обсудить отдельную модель для заданного диапазона площадей после согласования.
- **Критические ошибки:** безоговорочно удалить все большие дома или все IQR-выбросы; считать нетипичную цену доказанной ошибкой; выбирать произвольный порог как требование пользователя; запускать обучение неподтверждённой ML-задачи.
