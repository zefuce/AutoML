# Bank Marketing - результат исследования

**Задача.** Предсказать, согласится ли клиент открыть срочный банковский депозит, используя информацию, которая доступна перед звонком. Это нужно, чтобы выбирать клиентов для контакта.

**Данные.** UCI Bank Marketing, `bank-full.csv`: 45 211 строк, 16 входных признаков, один таргет `y`. Источник и пояснения к признакам: [UCI Machine Learning Repository](https://archive.ics.uci.edu/dataset/222/bank+marketing). Расчёты и графики приведены в `bank_marketing.ipynb`.

## 1. Первичный анализ

Таргет `y` принимает только `no` и `yes`, поэтому исходная постановка - бинарная классификация. По типам данных: 7 числовых и 9 категориальных входных признаков. Поскольку признаки относятся к разным моментам маркетинговой кампании, перед их использованием нужно уточнить, на каком этапе прогноз нужен бизнесу.

### Смысл признаков

| Признак | Что содержит | На что обратить внимание |
|---|---|---|
| `age` | Возраст клиента | Правдоподобный диапазон, возрастные группы |
| `job` | Профессия | Редкие категории, `unknown` |
| `marital` | Семейное положение | Связь с откликом не означает причинную связь |
| `education` | Образование | `unknown`, неравные размеры групп |
| `default` | Просрочка по кредиту | Малочисленность категории `yes` |
| `balance` | Средний годовой баланс, евро | Отрицательные значения, длинный правый хвост |
| `housing` | Жилищный кредит | Различия в доле откликов |
| `loan` | Потребительский кредит | Различия в доле откликов |
| `contact` | Канал последнего контакта | `unknown`; доступность до контакта |
| `day` | Число месяца последнего контакта | Нельзя восстановить хронологию без года |
| `month` | Месяц последнего контакта | Разное количество звонков по месяцам |
| `duration` | Продолжительность последнего звонка, сек. | Недоступна до завершения звонка |

| `poutcome` | Результат прошлой кампании | `unknown` обычно связан с отсутствием истории |
| `y` | Открыл депозит: `yes`/`no` | Целевая переменная |

## 2. Основные статистики и распределение таргета

| Показатель | Результат |
|---|---:|
| Всего объектов | 45 211 |
| `y = no` | 39 922 (88,30%) |
| `y = yes` | 5 289 (11,70%) |
| Возраст: минимум / медиана / максимум | 18 / 39 / 95 лет |
| Баланс: минимум / медиана / максимум | −8 019 / 448 / 102 127 евро |
| Продолжительность: минимум / медиана / максимум | 0 / 180 / 4 918 сек. |
| Контактов в текущей кампании: минимум / медиана / максимум | 1 / 2 / 63 |
| Контактов до кампании: медиана / максимум | 0 / 275 |
| Полных дубликатов строк | 0 |

Классы несбалансированы: положительный исход составляет только 11,70%. Поэтому высокая accuracy сама по себе ещё не означает, что модель умеет находить заинтересованных клиентов. Какие метрики важнее (например, PR-AUC, recall, precision или стоимость звонков), зависит от цели банка. Для подготовки данных достаточно зафиксировать этот риск.

## 3. Пропуски и специальные значения

Формальных `NaN` нет: 0 пропущенных ячеек, 0% по каждому признаку. Однако некоторые отсутствующие сведения обозначены строкой `unknown`.

| Признак | `unknown`, шт. | Доля строк |
|---|---:|---:|
| `job` | 288 | 0,64% |
| `education` | 1 857 | 4,11% |
| `contact` | 13 020 | 28,80% |
| `poutcome` | 36 959 | 81,75% |

Итого 52 124 ячейки `unknown`, или 7,21% ячеек среди 16 входных признаков. Это оценка доли специальных обозначений, а не процент формальных `NaN`. Для каждого столбца нужно понимать происхождение `unknown`: неуказанная профессия, неизвестный канал связи и отсутствие результата прошлой кампании - разные ситуации.

Отдельно проверено `pdays = -1`: таких строк 36 954 (81,74%). Согласно описанию UCI, это значит, что клиента не контактировали в предыдущей кампании. Во всех таких строках `poutcome = unknown`. У 5 клиентов `poutcome = unknown` встречается при наличии предыдущего контакта; это неоднозначные записи, но оснований исправлять их без первоисточника нет.

**Решение:** считать эти значения особенностью исходных данных; не заполнять их вручную и не удалять строки автоматически. Для агента важно распознавать специальные обозначения.

## 4. Ошибочные значения и выбросы

Проверены базовые ограничения: неотрицательные возраст и продолжительность, день месяца от 1 до 31, количество контактов текущей кампании не меньше 1. Нарушений этих проверок не выявлено.

В `balance` есть 3 766 отрицательных значений. Они могут отражать задолженность, поэтому таких клиентов не удаляем без оснований.

Метод IQR применён к `age`, `balance`, `duration` и `campaign` для предварительного поиска потенциальных выбросов:

| Признак | Количество | Доля строк |
|---|---:|---:|
| `age` | 487 | 1,08% |
| `balance` | 4 729 | 10,46% |
| `duration` | 3 235 | 7,16% |
| `campaign` | 3 064 | 6,78% |

`pdays` и `previous` рассмотрены отдельно. У 36 954 клиентов (81,74%) нет истории прошлых контактов: `pdays = -1`, `previous = 0`. У остальных 8 257 (18,26%) `pdays` находится в диапазоне 1–871 (медиана 194), `previous` - в диапазоне 1–275 (медиана 2). Из-за большого количества специальных и нулевых значений общий метод IQR здесь не используется.

## 6. Попарные корреляции и проверка гипотез

У числовых признаков сильных попарных линейных зависимостей немного. Например, `pdays` и `previous` имеют корреляцию около 0,455, но оба отражают историю прошлых контактов, при этом `pdays` содержит специальный код `-1`. Корреляция `day` и `campaign` около 0,162. Наибольшая линейная связь с бинарным таргетом - у `duration` (0,395). Далее `pdays` (0,104), `previous` (0,093) и `campaign` (−0,073).

Проверено три гипотезы:

1. **`pdays=-1` означает отсутствие предыдущих контактов.** Подтверждено описанием UCI и согласуется с таблицей `poutcome`: все 36 954 таких клиента имеют `unknown`. Пять дополнительных `unknown` требуют осторожной интерпретации.
2. **Длительность разговора сильно связана с ответом.** В первом квартиле `duration` доля `yes` равна 1,12%, в последнем - 29,44%. Гипотеза о статистической связи поддерживается данными. Но для прогноза до звонка признак недопустим, так как становится известен позже.
3. **Доля откликов различается по месяцам.** Наблюдаются большие различия между месяцами, но из этих данных нельзя доказать сезонный эффект: клиенты и кампании могли сильно различаться, а точных дат нет.

## 7. Итоги и эталон ожидаемых действий агента

| Что нужно решить | Обоснованный ориентир |
|---|---|
| Что предсказывать | `y`, согласие на депозит (`yes`/`no`) |
| Тип задачи | Бинарная классификация |
| Когда делаем прогноз | Уточнить у пользователя: до первого звонка, перед очередным звонком или после контакта |
| Метрика | Не ограничиваться accuracy; выбирать с учётом цены звонков и пропущенных потенциальных клиентов. PR-AUC - один из кандидатов |
| Дисбаланс | Замечать 11,70% положительных ответов |
| Пропуски | Различать `NaN`, `unknown` и специальный код `pdays=-1` |
| Ошибки и выбросы | Не удалять отрицательные `balance` и большие значения по одному формальному правилу |
| Утечка | Предупредить, что `duration` нельзя использовать при прогнозе до звонка |
| Доступность остальных признаков | Проверить `campaign`, `contact`, `day`, `month` относительно момента прогноза |
| Валидация | Проверять переносимость на будущие кампании; не объявлять случайное разбиение достоверной имитацией будущего. Для строгой временной проверки потребуется дата/идентификатор кампании |
