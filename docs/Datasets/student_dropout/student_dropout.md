# Predict Students' Dropout and Academic Success - результат исследования

**Задача.** Предсказать академический статус студента (`Dropout`, `Enrolled` или `Graduate`) по сведениям о поступлении и результатам обучения. Момент прогноза определяет, какие признаки допустимо использовать.

**Данные.** UCI Predict Students' Dropout and Academic Success, исходный `data.csv`: 4 424 строки, 37 столбцов, из них 36 входных признаков и таргет `Target`. Источник и описание полей: [UCI Machine Learning Repository](https://archive.ics.uci.edu/dataset/697/predict+students+dropout+and+academic+success). Расчёты и графики приведены в `student_dropout.ipynb`.

## 1. Первичный анализ

`Target` принимает три значения, поэтому исходная постановка - многоклассовая классификация. Все входные признаки сохранены в исходном виде. Многие целочисленные столбцы содержат коды категорий, а не непрерывные измерения.

### Смысл признаков

| Признак или группа | Что содержит | На что обратить внимание |
|---|---|---|
| `Marital status`, `Application mode`, `Application order` | Семейное положение и порядок поступления | Категориальные коды |
| `Course`, `Daytime/evening attendance` | Программа обучения и форма посещения | Разные размеры групп, кодировка |
| `Previous qualification`, `Previous qualification (grade)` | Предыдущее образование и балл | Категория и числовая оценка |
| `Nacionality`, `Displaced`, `International` | Происхождение и мобильность студента | Исходное имя `Nacionality` не исправлено |
| `Mother's qualification`, `Father's qualification`, `Mother's occupation`, `Father's occupation` | Сведения о родителях | Много категорий |
| `Admission grade`, `Age at enrollment` | Вступительный балл и возраст | Диапазоны и необычные значения |
| `Gender`, `Educational special needs` | Демографические сведения и особые потребности | Категориальные признаки |
| `Debtor`, `Tuition fees up to date`, `Scholarship holder` | Финансовый и стипендиальный статус | Зависит от момента измерения |
| `Curricular units 1st sem (...)` | Количество дисциплин, оценок, зачётов и успеваемость первого семестра | Недоступно при поступлении |
| `Curricular units 2nd sem (...)` | Аналогичные показатели второго семестра | Недоступно при поступлении и после первого семестра |
| `Unemployment rate`, `Inflation rate`, `GDP` | Макроэкономические показатели | Возможная привязка к году, даты в CSV нет |
| `Target` | Итоговый академический статус | Целевая переменная |

## 2. Таргет

| Класс | Количество | Доля |
|---|---:|---:|
| `Graduate` | 2 209 | 49,93% |
| `Dropout` | 1 421 | 32,12% |
| `Enrolled` | 794 | 17,95% |

Класс `Enrolled` представлен реже остальных. Для задачи определения риска отчисления нужно отдельно согласовать, сохраняется ли трёхклассовая постановка.

## 3. Пропуски и дубликаты

| Проверка | Результат |
|---|---:|
| Формальные `NaN` | 0 |
| Признаков с `NaN` | 0 |
| Полные дубликаты строк | 0 |
| Повторы наборов входных признаков | 0 |

В заголовке `Daytime/evening attendance` присутствует завершающий символ табуляции. Название `Nacionality` также оставлено как в исходном файле. В описании UCI указано, что датасет был предварительно обработан до публикации. Нулевые академические показатели требуют предметной интерпретации, а не автоматической замены на пропуски.

## 4. Диапазоны, распределения и выбросы

| Показатель | Результат |
|---|---:|
| Возраст: минимум / медиана / максимум | 17 / 20 / 70 лет |
| `Admission grade`: минимум / медиана / максимум | 95 / 126,1 / 190 |
| Нулевых `Curricular units 1st sem (grade)` | 718 |
| Нулевых `Curricular units 2nd sem (grade)` | 870 |

Все нулевые средние оценки совпадают с нулём одобренных дисциплин соответствующего семестра. По правилу 1,5 IQR:

| Признак | Медиана | IQR-сигналы | Доля строк |
|---|---:|---:|---:|
| `Age at enrollment` | 20 | 441 | 9,97% |
| `Admission grade` | 126,1 | 86 | 1,94% |
| `Curricular units 1st sem (evaluations)` | 8 | 158 | 3,57% |

Студенты старшего возраста и необычные значения количества оцениваний не считаются ошибочными только по методу IQR. Нулевые оценки не заменяются вручную.

## 5. Категориальные признаки и связь с таргетом

Проценты означают долю `Dropout` внутри группы.

| Признак | Наблюдение | Особенность |
|---|---|---|
| `Debtor` | `1`: 62,03% (503 студента); `0`: 28,28% (3 921) | Финансовый статус, связь не доказывает причинность |
| `Tuition fees up to date` | `0`: 86,55% (528); `1`: 24,74% (3 896) | Необходимо уточнить момент определения статуса |
| `Scholarship holder` | `1`: 12,19% (1 099); `0`: 38,71% (3 325) | Неравные размеры групп |
| `Course` | 17 кодов | Различия по образовательным программам |
| `Application mode` | 18 кодов | Есть малочисленные категории |

В ноутбуке приведены отдельные таблицы долей `Dropout` по `Gender`, `International`, `Displaced`, форме посещения, семейному положению и другим кодам. Наблюдаемые различия не устанавливают причинных зависимостей.

## 6. Результаты первого и второго семестров

Медианы одобренных дисциплин по классам:

| Класс | Первый семестр | Второй семестр |
|---|---:|---:|
| `Dropout` | 2 | 0 |
| `Enrolled` | 5 | 4 |
| `Graduate` | 6 | 6 |

Проверка числа одобренных дисциплин за второй семестр:

| Группа | Студентов | Доля `Dropout` |
|---|---:|---:|
| `approved = 0` | 870 | 83,56% |
| `approved > 0` | 3 554 | 19,53% |

Результаты обоих семестров существенно различаются между классами. При прогнозе на этапе поступления эти показатели недоступны.

## 8. Момент прогноза и ограничения данных

В исходном файле шесть показателей первого и шесть показателей второго семестра. При прогнозе на этапе поступления использовать их нельзя; после первого семестра доступны только уже полученные результаты. Наличие задолженности и актуальность оплаты также должны соответствовать моменту прогноза.

В таблице отсутствуют явные идентификаторы студентов и календарные даты. Невозможно воспроизвести строгое разделение по учебным наборам или последовательным периодам только на основании исходных полей.

## 9. Итоги и эталон ожидаемых действий агента

| Что нужно решить | Обоснованный ориентир |
|---|---|
| Что предсказывать | `Target`, один из трёх исходов `Dropout` / `Enrolled` / `Graduate` |
| Тип задачи | Многоклассовая классификация; бинарную постановку согласовать отдельно |
| Дисбаланс | Учитывать доли классов 32,12% / 17,95% / 49,93% |
| Пропуски | Формальных `NaN` нет; не трактовать нулевые оценки как пропуски без оснований |
| Категориальные коды | Не использовать кодовые значения учебных программ и статусов как непрерывную шкалу |
| Выбросы | Не удалять взрослые возрастные группы и необычные оценки только по IQR |
| Риск утечки | Исключать результаты последующих семестров при раннем прогнозе |
| Момент прогноза | Различать поступление, окончание первого и второго семестров |
| Метрика | С учётом трёх классов рассматривать macro-F1; при приоритете отчисления - recall по `Dropout` |
| Валидация | Учитывать отсутствие в CSV дат и идентификаторов для проверки на новых учебных наборах |

## Как воспроизвести

Открыть `student_dropout.ipynb` в VS Code или Jupyter, установить `pandas`, `matplotlib`, `seaborn` и выполнить ячейки сверху вниз. Исходный `data.csv` должен лежать рядом с ноутбуком.
