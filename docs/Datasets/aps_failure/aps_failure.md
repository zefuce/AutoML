# APS Failure at Scania Trucks - результат исследования

**Задача.** Определить, относится ли неисправность грузовика к компоненту пневматической системы APS (`class = pos`), по эксплуатационным показателям. Это нужно для выбора грузовиков, требующих проверки APS.

**Данные.** UCI APS Failure at Scania Trucks, `aps_failure_training_set.csv`: 60 000 строк, 170 входных признаков, один таргет `class`. Отдельно предоставлен официальный `aps_failure_test_set.csv` на 16 000 строк. Источник и описание: [UCI Machine Learning Repository](https://archive.ics.uci.edu/dataset/421/aps+failure+at+scania+trucks). Расчёты и графики приведены в `aps_failure.ipynb`.

## 1. Первичный анализ

Таргет `class` принимает значения `neg` и `pos`. Исходная постановка - бинарная классификация. Входные признаки числовые, их названия обезличенны. По описанию UCI данные содержат счётчики и интервалы гистограмм. Физический смысл отдельного столбца по названию определить нельзя.

### Смысл признаков

| Признак или группа | Что содержит | На что обратить внимание |
|---|---|---|
| `class` | Отказ относится к APS (`pos`) или нет (`neg`) | Целевая переменная, дисбаланс классов |
| `aa_000`, `ag_005`, `ba_000`, `ck_000` | Анонимизированные числовые измерения | Разные масштабы, пропуски и длинные хвосты |
| `br_000`, `bq_000`, `bp_000` | Анонимизированные признаки | Очень высокая доля пропусков |
| `cd_000` | Анонимизированный признак | Одно наблюдаемое значение и пропуски |
| `ag`, `ay`, `az`, `ba`, `cn`, `cs`, `ee` | Группы по десять интервалов гистограмм | Связанные измерения с общим префиксом |
| Прочие входные признаки | Анонимизированные счётчики и измерения | Проверяются распределения, пропуски и корреляции |

## 2. Таргет и стоимость ошибок

| Показатель | Результат |
|---|---:|
| Всего обучающих наблюдений | 60 000 |
| `class = neg` | 59 000 (98,33%) |
| `class = pos` | 1 000 (1,67%) |
| Стоимость ложного срабатывания (FP) | 10 |
| Стоимость пропущенного отказа (FN) | 500 |
| Отношение стоимости FN к FP | 50 |

Класс `pos` редок. Если всегда предсказывать `neg`, доля правильных ответов составит 98,33%, но стоимость пропущенных отказов на обучающей части - 500 000 условных единиц. Для постоянного прогноза `pos` стоимость ненужных проверок составит 590 000.

## 4. Дубликаты, ошибки и постоянные значения

Полных дубликатов строк и повторяющихся наборов входных признаков нет. Признаков с отрицательными наблюдаемыми значениями нет.

У `cd_000` только одно наблюдаемое значение - 1 209 600; ещё 676 строк содержат `NaN`. Без расшифровки показателей невозможно установить правдоподобные физические границы всех столбцов.

## 5. Распределения, выбросы и связь с таргетом

По четырём числовым признакам проверены распределения и IQR. Проценты относятся к заполненным строкам соответствующего признака.

| Признак | Медиана | IQR-сигналы | Доля заполненных строк |
|---|---:|---:|---:|
| `aa_000` | 30 776 | 5 627 | 9,38% |
| `ag_005` | 176 020 | 5 946 | 10,02% |
| `ba_000` | 679 486 | 4 918 | 8,29% |
| `ck_000` | 250 267,2 | 5 551 | 9,30% |

Распределения асимметричны, отдельные значения значительно превышают основные диапазоны. Метод IQR использован для поиска необычных значений, а не для автоматического удаления строк.

Медианы выбранных признаков по классам:

| Признак | `neg` | `pos` |
|---|---:|---:|
| `aa_000` | 30 416 | 584 994 |
| `ag_005` | 165 806 | 9 476 568 |
| `ba_000` | 663 991 | 10 972 571 |
| `ck_000` | 242 316,48 | 6 848 688,48 |

Для выбранных столбцов медианы у `pos` выше. Парные графики построены по выборке с искусственно изменённой долей `pos` - она используется только для визуального сравнения, не для оценки частот.

## 6. Группы признаков и корреляции

Обнаружены семь групп с десятью столбцами в каждой: `ag`, `ay`, `az`, `ba`, `cn`, `cs`, `ee`. Их префиксы соответствуют структуре интервальных гистограмм, описанной UCI.

Для расчёта связи с бинарным таргетом использованы 141 непостоянный признак с заполненностью не менее 90%. Наибольшие коэффициенты корреляции с `pos`:

| Признак | Корреляция |
|---|---:|
| `ci_000` | 0,553 |
| `bb_000` | 0,543 |
| `bv_000` | 0,542 |

На тепловой карте выбранных числовых признаков видны и сильные взаимные корреляции, например `aa_000` и `ci_000` (≈0,965). Эти связи не подтверждают причинного влияния. Из-за обезличивания нельзя определить, связаны ли они с устройством датчиков или способом формирования признаков.

## 7. Проверка исходного разбиения

Файл `aps_failure_test_set.csv` содержит 16 000 строк и 171 столбец, названия и порядок столбцов совпадают с обучающим файлом. Анализ содержимого тестовой части и обучение моделей не проводились. Явной временной метки в таблице нет, поэтому нельзя утверждать, что официальный тест отражает более поздний период.

## 8. Итоги и эталон ожидаемых действий агента

| Что нужно решить | Обоснованный ориентир |
|---|---|
| Что предсказывать | `class`, наличие отказа APS (`pos` / `neg`) |
| Тип задачи | Бинарная классификация |
| Дисбаланс | Учитывать 1,67% положительных примеров |
| Пропуски | Распознавать `na` как `NaN`, учитывать различия по признакам и классам |
| Неинформативность | Отдельно проверить `cd_000` с единственным наблюдаемым значением |
| Выбросы | Не удалять большие измерения по одному IQR без предметной проверки |
| Анонимизация | Не приписывать отдельным признакам неописанный физический смысл |
| Метрика | Учитывать стоимость FP = 10 и FN = 500; accuracy недостаточна |
| Риск переноса | Проверить, сохраняются ли связи пропусков и классов на новых данных |
| Валидация | Использовать официальный тест отдельно, не объявлять разбиение временным |
