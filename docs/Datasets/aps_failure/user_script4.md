# APS-04 - Запрос на неподдерживаемую кластеризацию

**Датасет:** APS Failure (`aps_failure_training_set.csv`)  
**Категория:** вне области  

## 1. Входные данные

**Запрос пользователя:**

> «А можно просто разбить все грузовики на группы, вообще без меток поломки? Кластеризацию хочу, не классификацию.»

**Вход для будущего теста:** исходный `aps_failure_training_set.csv` вместе с приведённым выше текстом.

## 2. Ручной анализ запроса

Результат извлечения требований из текста:

```json
{
  "goal": {
    "value": "разделить грузовики на группы без меток неисправностей",
    "status": "explicit"
  },
  "task_type": {
    "value": "clustering",
    "status": "explicit"
  },
  "target": {
    "value": null,
    "status": "explicit"
  },
  "metric": {
    "value": null,
    "status": "unknown"
  },
  "constraints": {
    "training_time": {
      "value": null,
      "status": "unknown"
    }
  },
  "requirements": {
    "use_labels": {
      "value": "не использовать метки неисправности",
      "status": "explicit"
    },
    "task_exclusion": {
      "value": "не решать задачу классификации",
      "status": "explicit"
    }
  },
  "conflicts": []
}
```

Пользователь прямо выбирает кластеризацию и отказывается от классификации. Отсутствие таргета - сознательное условие запроса, а не повод автоматически выбирать столбец `class`.

## 3. Ручное решение и конфигурация

- **Задача:** Запрошена кластеризация без целевой переменной. Даже несмотря на наличие `class` с метками `neg` и `pos`, этот столбец не следует назначать таргетом: пользователь явно исключил обучение по меткам.
- **Область проекта:** Согласованный MVP поддерживает бинарную и многоклассовую классификацию и регрессию на размеченной таблице. Кластеризация отсутствует среди допустимых `problem_type` AutoGluon Tabular для проекта.
- **Решение:** Сообщить о неподдерживаемом типе задачи и не запускать обучение. Возможность кластеризации через другие инструменты или обсуждение иной постановки допустимы только как отдельная альтернатива, а не как незаметная замена запроса.

**Кандидат конфигурации:** не формируется.

Для этой постановки корректной финальной конфигурации AutoGluon Tabular в рамках проекта нет. Наличие в CSV меток отказа не разрешает менять задачу без согласия пользователя.

## 4. Критерии проверки агента

- **Обязательные результаты:** агент распознаёт явный запрос на кластеризацию без меток, объясняет ограничение проекта и не формирует конфигурацию классификации или регрессии.
- **Допустимые альтернативы:** кратко предложить использовать другой инструмент для кластеризации либо спросить, хочет ли пользователь отдельно рассмотреть задачу прогнозирования отказа APS.
- **Критические ошибки:** назначить `class` таргетом и сгенерировать `binary`-конфигурацию; заявить, что кластеризация поддерживается текущими параметрами проекта; запустить обучение по меткам вопреки явному требованию.
