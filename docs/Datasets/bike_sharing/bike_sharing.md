# Bike Sharing - результат исследования

**Задача.** Предсказать количество аренд велосипедов за следующий час (`cnt`), используя информацию, доступную до его начала. Это нужно для планирования спроса и распределения велосипедов.

**Данные.** UCI Bike Sharing, `hour.csv`: 17 379 строк, 17 столбцов, один таргет `cnt`. Источник и описание признаков: [UCI Machine Learning Repository](https://archive.ics.uci.edu/dataset/275/bike+sharing+dataset). Расчёты и графики приведены в `bike_sharing.ipynb`.

## 1. Первичный анализ

`cnt` - неотрицательное целочисленное количество аренд за час. Исходная постановка - регрессия. Часть признаков закодирована целыми числами, но по смыслу относится к категориям или календарю.

### Смысл признаков

| Признак | Что содержит | На что обратить внимание |
|---|---|---|
| `instant` | Порядковый номер записи | Идентификатор, не характеристика спроса |
| `dteday` | Дата наблюдения | Временной порядок и повторение даты в отдельных кодах |
| `season` | Сезон, код 1–4 | Категориальный признак |
| `yr` | Год: 0 - 2011, 1 - 2012 | Изменение спроса между годами |
| `mnth` | Месяц, код 1–12 | Календарная сезонность |
| `hr` | Час суток, код 0–23 | Суточный профиль спроса |
| `holiday` | Признак праздника | Небольшая группа праздничных часов |
| `weekday` | День недели, код 0–6 | Рабочие и выходные дни |
| `workingday` | Рабочий день | Разные профили по часам |
| `weathersit` | Состояние погоды, код 1–4 | Редкие категории, доступность прогноза погоды |
| `temp` | Нормированная температура | Связь с `atemp` |
| `atemp` | Нормированная ощущаемая температура | Сильная корреляция с `temp` |
| `hum` | Нормированная влажность | Нулевые значения в один день |
| `windspeed` | Нормированная скорость ветра | Неравномерное распределение |
| `casual` | Аренды незарегистрированных пользователей | Часть целевой переменной, утечка |
| `registered` | Аренды зарегистрированных пользователей | Часть целевой переменной, утечка |
| `cnt` | Общее число аренд за час | Целевая переменная |

## 2. Основные статистики и таргет

| Показатель | Результат |
|---|---:|
| Всего наблюдений | 17 379 |
| Дат в файле | 731 |
| Период | 01.01.2011 - 31.12.2012 |
| `cnt`: минимум / медиана / максимум | 1 / 142 / 977 |
| `cnt`: среднее | 189,46 |
| `cnt = 0` | 0 |
| Наблюдений в 2011 / 2012 | 8 645 / 8 734 |

Распределение `cnt` асимметрично: большие значения встречаются реже, чем малые и средние. Нулевого спроса в имеющихся строках нет. Отсутствующие часы рассматриваются отдельно.

## 3. Пропуски и временная структура

Формальных `NaN` нет. Полных дубликатов строк и повторов сочетания `dteday + hr` также нет.

| Проверка | Результат |
|---|---:|
| Отсутствующие строки почасовой сетки | 165 |
| Дни с 24 часовыми записями | 655 |
| Дни с неполным набором часов | 76 |
| Минимальное число записей за день | 1 (29.10.2012) |

Значения рассчитаны по непрерывной часовой сетке от первого до последнего наблюдения. Причина отсутствующих строк в исходном описании не указана. Отсутствие записи не равно нулевому числу аренд.

## 4. Ошибки, редкие значения и выбросы

Нарушений проверенных диапазонов нет: `cnt` неотрицателен, `hr` от 0 до 23, `mnth` от 1 до 12, `weathersit` от 1 до 4, нормированные погодные признаки находятся в интервале от 0 до 1.

`hum = 0` встречается 22 раза, все записи относятся к 10.03.2011. Это возможная особенность измерений.

Метод IQR применён к количеству аренд и скорости ветра как предварительная проверка необычных значений:

| Признак | IQR-сигналы | Доля строк |
|---|---:|---:|
| `cnt` | 505 | 2,91% |
| `windspeed` | 342 | 1,97% |

Календарные коды не проверяются общим IQR: их значения обозначают категории. Результаты IQR не используются для автоматического удаления наблюдений.

## 5. Исследование признаков и связи с таргетом

Для категориальных признаков посчитаны размеры групп, среднее и медиана `cnt`. Для числовых - распределения, корреляции и парные графики.

| Признак | Наблюдение | Интерпретация |
|---|---|---|
| `instant` | Корреляция с `cnt` ≈0,278 | Индекс отражает ход времени, не является самостоятельным фактором спроса |
| `dteday` | 731 дата, в 76 днях неполная часовая сетка | Для валидации нужен временной порядок |
| `season` | Средний `cnt`: сезон 1 - 111,11; сезон 3 - 236,02 | Спрос различается по сезонам |
| `yr` | 2011 - 143,79; 2012 - 234,67 | Между годами заметное изменение уровня спроса |
| `mnth` | Январь - 94,42; сентябрь - 240,77 | Средний спрос различается по месяцам |
| `hr` | 04:00 - 6,35; 17:00 - 461,45 | Выраженный суточный профиль |
| `holiday` | 500 праздничных часов; средний `cnt` 156,87 | Группа меньше непраздничной |
| `weekday` | По дням недели средние различаются | Разница зависит также от часа |
| `workingday` | Рабочий день - 193,21; нерабочий - 181,41 | Важны различия почасовых профилей |
| `weathersit` | Код 1 - 204,87; код 3 - 111,58; код 4 - всего 3 строки | Наблюдаемая связь с погодой, четвёртая группа очень мала |
| `temp` | Корреляция с `cnt` ≈0,405 | Положительная линейная связь |
| `atemp` | Корреляция с `cnt` ≈0,401 | Сильная связь с `temp` |
| `hum` | Корреляция с `cnt` ≈−0,323; 22 нулевых значения | Отрицательная линейная связь; проверить нули |
| `windspeed` | Корреляция с `cnt` ≈0,093 | Слабая линейная связь |
| `casual` | Корреляция с `cnt` ≈0,695 | Компонент фактического числа аренд |
| `registered` | Корреляция с `cnt` ≈0,972 | Компонент фактического числа аренд |

Сравнение графиков `hr` и `workingday` показывает различающиеся профили: в рабочие дни заметны утренний и вечерний пики, в нерабочие часы нагрузка смещена к середине дня. Средние по всем часам скрывают эту структуру.

## 6. Корреляции и проверки гипотез

**`temp` и `atemp`.** Корреляция ≈0,988. Признаки несут близкую информацию, окончательное решение об их использовании относится к этапу конфигурации и моделирования.

**Утечка через компоненты спроса.** Во всех 17 379 строках выполняется равенство `cnt = casual + registered`. При прогнозировании до начала часа оба компонента недоступны, поэтому их нельзя использовать как входные признаки.

**Календарные коды.** `yr`, `mnth` и `weekday` согласуются с `dteday` во всех строках. `instant` соответствует порядку записей. Временной индекс не следует принимать за независимый признак без учёта момента прогноза.

**Влияние периода.** Средний спрос увеличился с 143,79 в 2011 году до 234,67 в 2012 году. Случайное разбиение перемешает наблюдения разных периодов.

## 7. Итоги и эталон ожидаемых действий агента

| Что нужно решить | Обоснованный ориентир |
|---|---|
| Что предсказывать | `cnt` - количество аренд в час |
| Тип задачи | Регрессия |
| Момент прогноза | Уточнить, прогнозируется ли следующий час и какие погодные данные доступны заранее |
| Метрика | MAE или RMSE с учётом цены ошибок и значимости пикового спроса |
| Пропуски | Отделять формальные `NaN` от отсутствующих часовых наблюдений |
| Возможные ошибки | Проверить `hum = 0` в один день; не исправлять без основания |
| Выбросы | Не удалять пики `cnt` и скорости ветра только по IQR |
| Утечка | Исключить `casual` и `registered` для прогноза до часа |
| Идентификатор | Не использовать `instant` как содержательный предиктор |
| Категории | Учитывать смысл `season`, `mnth`, `hr`, `weekday`, `weathersit`, несмотря на числовые коды |
| Валидация | Сохранять временной порядок, отдельно оценивать переносимость на будущие периоды |

## Как воспроизвести

Открыть `bike_sharing.ipynb` в VS Code или Jupyter. Установить `pandas`, `matplotlib`, `seaborn` и выполнить ячейки сверху вниз. Файл `hour.csv` должен лежать рядом с ноутбуком.
